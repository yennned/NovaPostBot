# 01 — Обзор, контекст и ключевые решения

## Контекст

Telegram-бот личного кабинета фулфилмента Новой Почты. Работа ведётся **только**
в `/Users/yenin/Desktop/NovaPostBot`.

**Цель:** рабочий, поддерживаемый бот с ролевой моделью (клиент → менеджер →
владелец), god-mode для разработки, корректными уведомлениями/подтверждением
клиентов и аккуратным процессом разработки через GitHub с защищённым `main`.

**Статус:** фазы 0–7 закрыты, бот работает в проде (Hetzner + Neon), деплой
автоматический. Фактическое состояние работ — [PROGRESS.md](../PROGRESS.md),
что осознанно не реализовано — [ROADMAP.md](ROADMAP.md).

## Объёмы и сайзинг

Входные: ≤ **20 клиентов** на старте, ≤ **15 000 ТТН/мес**.

- **Отправки:** ~500 ТТН/день, ~1/мин (пики 2–3/мин) — нагрузка очень лёгкая.
- **Позиции ТТН:** ~30–45 тыс. строк/мес.
- **Наименования на складе:** ~2 000–20 000 (планово ~10 000 SKU на всех).
- **Google Sheets (склад):** книга «Склад» ~120 тыс. ячеек из лимита 10 млн
  (~1%); API-квоты с запасом. Узкого места нет.
- **PostgreSQL:** < 1 млн строк/год (shipments+items+audit+поддержка) — мелочь,
  без партиционирования.
- **Compute:** бот+воркер+Redis на 1–2 vCPU / 2–4 ГБ RAM с запасом.

Узкое место — скорость API НП, а не БД. Поэтому лёгкая очередь (Redis+worker) и
кэш справочников НП.

## Хостинг (развёрнуто)

Вариант A выбран и работает; прод живой.

- **VPS:** Hetzner **CPX21** (3 vCPU / 4 ГБ / 80 ГБ) — бот + воркер + Redis в
  Docker. Деплой автоматический (merge в `main` → GHCR → SSH), см.
  [CONTRIBUTING.md](../CONTRIBUTING.md) и [ROADMAP.md](ROADMAP.md).
- **БД:** managed Postgres **Neon**, план **Launch с отключённым scale-to-zero**
  (БД всегда «тёплая»); автобэкапы/PITR/SSL на стороне Neon. **Neon Free — НЕ для
  прода:** обязательный scale-to-zero через 5 мин простоя (не отключается) даёт
  холодные старты на каждый запрос после простоя; годится только для локальной
  разработки. Отдельного staging-контура у проекта нет (упразднён 2026-07-31).
- **Redis:** на VPS в Docker = $0. **Telegram/НП/Sheets API — бесплатно.**
- **Порядок инфраструктуры: ~€10–15/мес.** Точные суммы зависят от тарифов
  Hetzner и потребления Neon — сверять по счетам, а не по этому файлу.
- Код провайдеро-независим (`DATABASE_URL`/`REDIS_URL`) — смена провайдера без
  правок. Managed-БД с Фазы 0.

**Альтернативы (отклонены при выборе):** DigitalOcean (одно окно, но дороже);
один VPS со self-hosted Postgres (дешевле, но ручные бэкапы — риск для прода).
